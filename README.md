# jellyfin-oled
Custom Scyfin OLED theme overrides for Jellyfin.
- **Base:** Scyfin + OLED variant
- **Accents:** Purple-dominant with electric blue sparks
- **Features:** 
  - True black background
  - Proud but restrained card glow
  - Gradient progress + volume bars
  - Clean text-only buttons (no bubbles)
  - Subtle hover shimmer
